# Todo List

An early JavaScript to-do application built while learning how browser-based applications manage user input, application state and dynamic page updates.

The project is kept largely as it was built at the time rather than being retrospectively modernised. It represents one of the earliest stages of my development work and is useful as part of the progression toward later projects.

## Features

- add tasks with due dates;
- validate required input;
- delete existing tasks;
- render the task list dynamically in the browser;
- persist tasks between sessions using `localStorage`.

## Built With

- HTML
- CSS
- JavaScript
- Bootstrap
- Browser `localStorage`

## Retrospective Context

The main value of this project is the programming practice it provided: working with arrays and objects, DOM manipulation, event listeners, validation, rendering state into HTML, and simple browser-side persistence.

It is intentionally presented as an early learning project rather than rewritten to look like current work.
